# 求职自动投递助手（qzzdh）

一个基于 Chrome Manifest V3 的浏览器扩展，用于在主流求职网站（当前深度适配 **BOSS 直聘**）批量投送简历，并支持多维度智能筛选。

## ✨ 功能特性

### 智能筛选
| 筛选维度 | 说明 |
|---|---|
| 工作年限 | 应届 / 1年以下 / 1-3年 / 3-5年 / 5-10年 / 10年以上（多选） |
| 学历要求 | 学历不限 ~ 博士（多选） |
| 城市地区 | 关键词匹配，逗号分隔多个城市 |
| 职位关键词 | 职位名包含任一关键词才投递（大小写不敏感） |
| 排除关键词 | 职位名/公司名命中即跳过（如"外包、实习生"） |
| 招聘者活跃时间 | 只投最近活跃的招聘者，避开"半年前活跃"的僵尸岗位 |
| 公司规模 | 0-20人 ~ 10000人以上（多选，可排除微型公司） |

### 批量投递（BOSS 直聘 queue-detail 编排）
BOSS 直聘列表卡片没有直接投递按钮，插件采用三段式编排：

```
列表页扫描筛选 → 收集职位详情链接 → 后台逐页打开详情 → 自动点击"立即沟通"
```

- 投递间隔可配置（1~60 秒）+ 随机抖动，模拟人工节奏；
- 最大投递数上限，防止误操作；
- 15 秒看门狗，详情页卡死自动跳过；
- 随时一键停止，停止后不再发起新沟通；
- 预演模式：只筛选标记，不实际投递。

### 页面内右侧栏控制台
所有筛选设置、操作按钮、运行统计、日志全部常驻在**页面右侧栏**，无需打开扩展弹窗：

- 扫描 / 匹配 / 已投递 / 跳过 实时统计与进度条；
- 卡片可视化标记：绿框=符合、灰框=跳过（附原因）、蓝框=已投递；
- 匹配为 0 时输出跳过原因统计（如 `年限不符×63、学历不符×16`）与示例职位名，便于定位筛选问题。

### 抗改版能力（站点结构自适应）
网站 DOM 改版后类名常被混淆，插件内置多级兜底：

1. 配置选择器（`config/sites.js` 集中维护）；
2. 备用选择器列表；
3. **按详情链接聚类**定位职位主列表（类名会变，链接不会）；
4. 按 `job-card*` 类名特征聚类兜底；
5. 字段解析多级兜底（职位名/公司/地区/经验/学历/规模/活跃度）。

## 📦 安装使用

1. Clone 或下载本项目：
   ```bash
   git clone https://github.com/<你的用户名>/qzzdh.git
   ```
2. 打开 Chrome，访问 `chrome://extensions/`；
3. 开启右上角 **开发者模式**；
4. 点击 **加载已解压的扩展程序**，选择项目根目录（`qzzdh` 文件夹）；
5. 登录 BOSS 直聘并进入职位搜索页，页面右侧会出现助手侧栏；
6. 设置筛选条件 → 点击 **扫描筛选** 预览 → 点击 **开始投递**。

> ⚠️ 请合理设置投递间隔与单次数量（建议间隔 ≥ 3 秒、单次 ≤ 50 个），过于频繁可能触发网站风控。请遵守各网站的使用条款。

## 🗂 项目结构

```
qzzdh/
├── manifest.json        # MV3 清单（权限、注入规则）
├── background.js        # Service Worker：BOSS 队列编排、徽标、通知
├── content.js           # 核心脚本：扫描/解析/筛选/投递/右侧栏 UI
├── content.css          # 右侧栏与卡片标记样式
├── popup.html/js/css    # 扩展弹窗（备用入口，与侧栏共享存储）
├── config/
│   └── sites.js         # 站点选择器配置中心 + 经验/学历词典
├── icons/               # 扩展图标
└── tools/
    ├── gen_icons.py     # 纯 Python PNG 图标生成器
    └── self_check.py    # 自检脚本（清单合法性/括号配平）
```

## 🔧 技术栈

- Chrome Extension **Manifest V3**（Service Worker + Content Script + chrome.storage/tabs/scripting）
- 原生 JavaScript（无框架、无构建步骤，加载即用）
- 消息协议：`QZZDH_CONTROL / QZZDH_PROGRESS / QZZDH_BOSS_START / NEXT / STOP`

## 🧪 自检

```bash
python tools/self_check.py
```

校验 manifest 合法性、引用文件完整性、PNG 头、JS 括号配平。

## 🔌 适配新站点 / 选择器失效

只需修改 `config/sites.js` 中对应站点的选择器配置，无需改动核心逻辑。
